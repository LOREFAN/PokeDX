# PokéDX

Site de fã do universo Pokémon com Pokédex, jogo da memória e quiz.

**[Acessar demo](https://pokedx.lovable.app/)**

## Funcionalidades

- **Pokédex:** 50 Pokémon (clássicos e raros) com busca por nome e filtro por categoria.
- **Jogo da memória:** 25 fases de dificuldade crescente.
- **Quiz:** 25 perguntas divididas em 3 etapas.

## Tecnologias e como foram usadas

| Tecnologia | Uso no projeto |
|---|---|
| React 19 | Interface organizada em componentes reutilizáveis |
| TypeScript | Tipagem do código para evitar erros |
| TanStack Start e Router | Estrutura do app e navegação entre Início, PokéDX, Jogo da Memória e Quiz |
| Tailwind CSS 4 | Estilização e layout responsivo |
| shadcn/ui e Radix UI | Componentes de interface acessíveis e personalizáveis |
| Lucide React | Ícones |
| Vite | Ambiente de desenvolvimento e build |
| Vitest e Testing Library | Testes automatizados |
| ESLint e Prettier | Padronização e qualidade do código |

## Como rodar localmente

```bash
git clone https://github.com/LOREFAN/PokeDX.git
cd PokeDX
npm i
npm run dev
```

Outros comandos: `npm run build` (gerar versão final), `npm test` (testes) e `npm run lint` (verificar o código).
